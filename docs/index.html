Cursor Agents window on the MX Creative Keypad

Live status of your Cursor Agents window agents on the Logitech MX Creative Keypad. Press a key to jump to one.

A agent key shows its most urgent chat, so a side chat waiting for you colors the whole agent.

Actions

Drag them onto keys in Logi Options+ (All actions → Cursor Agents Window).

ActionWhat it does
Recent chat 1–9The Nth chat across all agents, side chats included, most urgent first. Press opens it; long press on a main chat archives the agent after a second press.
New agentBrings up the Agents window and starts a new agent. Reads Start Cursor when Cursor is closed.
Agents window (folder)One key per agent with a chat-count badge. Long press opens the agent menu: Back, New chat (side chat), Archive, and its chats.
Shortcut keysSidebar, Right Sidebar, Files, Terminal, Browser, Changes, Search. The Agents window comes to the front, then the keys are sent.
Cursor shortcuts (folder)New plus the seven shortcuts on one Keypad page.

The Agents window folder

A press opens the agent. A long press opens its menu. Archive asks for a second press within 3 seconds.

Install

  1. Requirements: macOS, Cursor 3.27 or later, Logi Options+ with Logi Plugin Service 6.4 or later, and an MX Creative Keypad or Loupedeck CT.
  2. Download CursorAgentsWindow_<version>.lplug4 from the latest release.
  3. Double-click it. Logi Options+ installs the plugin.
  4. In Options+, select the Keypad, open All actions, and drag the actions onto keys.

Privacy

Cursor has no local API for agents, so the plugin reads a copy of Cursor's local state database, read-only, once a second. It never writes to Cursor's storage, never reads message text, and sends nothing anywhere.
